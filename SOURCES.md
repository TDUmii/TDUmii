# Sources

- The current design is **C1 - Pixel Magazine**, selected by the user from three visual directions, refined, then explicitly approved for implementation. It uses cream, navy, mint and amber with three illustrated project links.
- The native GitHub edition now has a custom T/D owner mark, an original-media night scene, larger project illustrations and capability rails. The activity flame is anchored beside its heading. Native rendering and per-character motion are separated into documented modules; [the source map](docs/SOURCE-MAP.md) explains the edit/build path.
- `c1-bridge-art.png`, `c1-quiet-art.png` and `c1-automation-art.png` are generated illustrations made for this profile from the approved C1 reference. They are artwork, not application screenshots. Each PNG embeds its exact generation prompt. `assets/c1-art-source.json` records their SHA-256 hashes and provenance.
- `scripts/build_sprite_motion.py` builds the three animated SVG sprites using SVG clips, masks and vector overlays around the original PNG payloads. The raster artwork is unchanged. `assets/c1-motion-source.json` records source hashes, output dimensions and loop timing. Each native project image inlines its rig; its reduced-motion state is the exact original PNG. Internal motion includes Bridge head-and-antenna tilt with blinking and terminal blocks, a bowed QuietShare page turn anchored to the cream-paper junction with the original covers restored in front, and Automation replay-arrow advance/reset independent of its gear and cursor actions.
- The Nyan Cat GIF is the exact file requested by the user: [GIPHY source page](https://giphy.com/gifs/cat-pixel-art-nyan-7lsw8RenVcjCM). It was downloaded directly over HTTP and remains unchanged in frames, color and timing. Source metadata and the original SHA-256 are retained in `assets/nyan-cat-source.json`. Its still PNG is a first-frame accessibility fallback.
- The [ringed planet](https://pixor.art/library/scifi/sci-planet/) and [tin toy robot](https://pixor.art/library/toys/toy-robot/) are original GIF downloads from Pixor's CC0 library. The [blue flame](https://opengameart.org/content/fire-0) is by Spring Spring (Julie Damsgaard), CC0. Original download URLs, byte sizes and hashes are in `assets/pixel-assets-source.json`. Static PNGs are first-frame motion fallbacks.
- Sora is self-hosted and embedded in native SVGs. Its SIL Open Font License is retained in `assets/Sora-OFL.txt`.
- Repository counts, stars, languages and project links come from the unauthenticated public GitHub API. Contribution counts come from labeled day cells in the public GitHub calendar. The snapshot date is displayed. No private repository metadata is used.
- Language bars count public non-fork repositories by primary GitHub language. They are not proficiency scores or code-byte percentages. Active days count dates with at least one contribution; zero-contribution dates remain present in the calendar. The decorative orbit is masked to active dates.
- The site is static. `python scripts/update_profile.py` refreshes public data and the native README assets. `python scripts/build_offline.py` versions website assets and builds the self-contained offline page. It packages only assets referenced by the website.
- Earlier actual-interface captures have provenance in `assets/work-sources.json`; the current C1 layout uses its dedicated illustrations.
